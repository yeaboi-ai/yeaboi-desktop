# Design Library

> A reference library for AI-assisted web development.

## START HERE: `HARNESS.md`

**Always read `HARNESS.md` first.** It identifies your project type and routes you to the exact files, techniques, and reference sites to use. Do not skip it.

## Workflow

1. Read **HARNESS.md** — identify project type, get your recipe
2. Recipe tells you which files to read and which techniques to combine
3. Check the **font rotation rule** — never reuse fonts across projects
4. Build, layering multiple techniques (not just one or two)
5. Run **13-checklist.md** before shipping
