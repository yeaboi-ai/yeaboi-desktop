# Recipe W: Fitness / Wellness

## Quick ref

- **When:** Gyms, yoga studios, CrossFit boxes, health apps, wellness brands, personal trainers.
- **Token budget:** ~15k (HARNESS + color + typography + motion + page-archetypes + anti-similarity).
- **Files to read:** `02-color.md`, `01-typography.md`, `05-motion.md`, `07-page-archetypes.md`
- **Personality fit:** Primary — Bold. Strong — Professional, Playful, Warm/Human, Organic.

## Page flow intent

Match the INTENSITY of the activity. A CrossFit box site feels different from a yoga studio.

Core rhythm: `high-energy video/photo hero → class schedule (filterable grid, not a PDF) → trainer profiles with action shots → trial/first-visit CTA → pricing (simple, 2-3 tiers) → location + facilities gallery`.

The trial CTA should appear early (above fold) AND at the bottom. Mobile-first — most users are searching on their phone after a workout.

## Techniques

- High-energy hero: video of movement/activity or bold typographic statement
- Class schedule as clean, filterable grid
- Trainer profiles with action photography (not headshots)
- Pricing tiers with clear comparison (2-3 options)
- Transformation/results section with real member photos
- Trial/first-visit CTA prominent
- Location section with facilities gallery

## Font direction

Bold, energetic sans for headings. Clean sans for body. The typography should feel like it MOVES — tight tracking, heavy weight, uppercase.

## Color

Energy-dependent. CrossFit = dark + neon. Yoga = earth tones + cream. Boxing = black + red. Pilates = soft pastels. Match the intensity of the activity.

## Motion budget

MEDIUM. Bold entrance animations. Video is key. But don't sacrifice page speed — many users are on mobile searching "gym near me."

## Anti-patterns

Shirtless mirror selfies as hero. Overwhelming class schedules. Hidden pricing. "No pain no gain" cliche copy.
