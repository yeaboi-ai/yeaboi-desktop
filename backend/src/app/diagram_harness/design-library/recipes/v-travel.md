# Recipe V: Travel / Tourism

## Quick ref

- **When:** Destinations, tours, hospitality booking, resort, cruise, adventure travel.
- **Token budget:** ~16k (HARNESS + imagery + motion + page-archetypes + color + anti-similarity).
- **Files to read:** `06-imagery-texture.md`, `05-motion.md`, `07-page-archetypes.md`, `02-color.md`
- **Personality fit:** Primary — Editorial, Bold. Strong — Professional, Playful, Luxury, Warm/Human, Organic.

## Page flow intent

ASPIRATION → LOGISTICS. Sell the dream first, then make booking easy.

Core rhythm: `cinematic destination hero (video or parallax photography) → search/booking widget (prominent, not buried) → curated experiences (not a dump of all offerings) → testimonials with destination-specific imagery → interactive map → seasonal highlights`.

The search widget is the product — it should feel as polished as the photography. Two structures: discovery page (selling the destination) vs booking flow (pure utility, no decoration).

## Techniques

- Full-bleed destination photography as hero (cinematic, aspirational)
- Parallax layers for depth (Joby multi-layer pattern)
- Search/booking widget as primary CTA in hero
- Image gallery with lightbox and location captions
- Itinerary as visual timeline
- Testimonials with destination-specific photos
- Map integration showing destinations
- Season/calendar indicators

## Font direction

Elegant serif for destination names + clean sans for booking UI. The serif sells the dream, the sans handles the logistics.

## Color

Destination-driven. Beach = warm blues/sand. Mountain = deep greens/stone. City = moody darks/neon. Let the destination set the palette.

## Motion budget

MEDIUM-HIGH. Travel sells through visual immersion. Parallax, scroll reveals, image transitions. Keep booking UI fast and functional.

## Anti-patterns

Overwhelming search forms above fold. Tiny destination cards. Stock beach photos. Calendar widgets that take 5 clicks to select a date.
