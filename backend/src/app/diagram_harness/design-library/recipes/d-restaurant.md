# Recipe D: Restaurant / Hospitality

## Quick ref

- **When:** Dining, hotels, venues, experiences, cafés, food brands.
- **Token budget:** ~16k (HARNESS + color + typography + motion + page-archetypes + anti-similarity).
- **Files to read:** `02-color.md`, `01-typography.md` > Luxury/Editorial, `05-motion.md`, `07-page-archetypes.md`
- **Personality fit:** Primary — Editorial, Warm/Human, Organic/Natural. Strong — Professional, Playful, Luxury.

## Page flow

```
[Full-viewport hero SLIDESHOW — clip-path transitions between 3-4 food/interior photos. Auto-advancing, with dot navigation at bottom. Chef quote or restaurant tagline overlaid.]
    ↓ scroll reveals content BENEATH the hero (hero stays pinned briefly)
[Philosophy strip — one sentence in large serif across full width. Background color shifts to warm tone.]
    ↓
[Menu highlights — NOT the full menu. 3-4 hero dishes, each: photo left/right alternating + dish name + one-line description + price. Asymmetric layout.]
    ↓
[Full-bleed interior photograph — no text except maybe a pull quote. The image IS the section.]
    ↓
[Practical info — split panel:
  LEFT: Hours, address, phone (click-to-call), map
  RIGHT: Reservation widget or CTA button
  This is the ONLY dense-info section.]
    ↓
[Instagram feed or photo mosaic — grid of real photos, links to social]
    ↓
[Footer — minimal. Logo + address + social links. Reservation button persists.]
```

Key: Photography-forward. At least 50% of viewport time should be images. The food sells the restaurant, not the copy.

## Techniques

- Clip-path hero image slideshow between food/interior photos (Bec Restaurant)
- Warm non-obvious color palette — NOT dark/moody by default (Bec: blush pink + navy + salmon)
- Serif display type at large scale for headings (PP Woodland pattern)
- Marquee ticker for key offerings or philosophy
- Rotating decorative elements (Bec: shape-rotate keyframe)
- Modal overlay for specials/menus
- Reservation CTA persistent but not aggressive
- Photography-forward — food photography IS the design

## Font direction

Organic serif (display, light to medium weight) + geometric sans (body, for UI/buttons). The serif carries warmth. See `01-typography.md` > Luxury/Editorial.

## Color

Warm. Study palettes outside tech — Provençal, Mediterranean, earth tones. Three colors with clear roles (background, text, accent). See `02-color.md` > Bec Restaurant pattern.

## Motion budget

MEDIUM. Hero slideshow transitions (clip-path, 1.2s dramatic easing). Subtle scroll reveals. Hover effects on menu items. No scroll hijacking — users need to find information quickly.

## Reference sites

Bec Restaurant.

## Anti-patterns

Dark moody "fine dining" cliche. Stock food photography. Tiny unreadable menu text. Popup reservation widgets covering content.
