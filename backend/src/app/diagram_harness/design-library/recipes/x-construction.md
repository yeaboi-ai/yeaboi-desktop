# Recipe X: Construction / Architecture

## Quick ref

- **When:** Builders, architects, engineering firms, developers (property), interior design studios.
- **Token budget:** ~14k (HARNESS + imagery + typography + page-archetypes + anti-similarity).
- **Files to read:** `06-imagery-texture.md`, `01-typography.md`, `07-page-archetypes.md`
- **Personality fit:** Primary — Professional. Strong — Brutalist, Technical.

## Page flow intent

WORK SPEAKS. The portfolio is the product. For architects: think gallery with editorial captions. For builders: think before/after proof.

Core rhythm: `flagship project as hero (full-bleed photography) → project list with hover-reveal imagery → capabilities (not "services" — capabilities) → awards/press → contact`.

Architecture firms can be experimental with layout. Construction companies should be straightforward and trustworthy. Both: real project photography is non-negotiable.

## Techniques

- Project photography as hero — completed work, dramatic angles
- Before/after sliders for renovations
- Project grid with hover-reveal details (location, type, year)
- Service areas or capabilities as simple icon-free list
- Awards/certifications bar
- Client testimonial with project photo context
- "Spaceship instruction manual" aesthetic for technical firms (diagrams, specs, thin lines)

## Font direction

Strong geometric sans. Architecture firms can go bold/experimental. Builders should stay clean/professional. Serif for firm name if going premium.

## Color

Material-inspired. Concrete greys, steel blues, timber browns, glass reflections. Dark backgrounds for dramatic project photography.

## Motion budget

LOW-MEDIUM. Let project photography do the work. Scroll reveals for projects. Before/after slider interaction. No flashy effects.

## Anti-patterns

Hard hat stock photos. Yellow/black hazard stripe aesthetics. Dense project specification tables as primary content.
