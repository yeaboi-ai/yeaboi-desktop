# Recipe S: Personal / Newsletter

## Quick ref

- **When:** Personal brand, writer, newsletter, indie maker, portfolio-as-notebook.
- **Token budget:** ~13k (HARNESS + imagery + typography + layout + anti-similarity).
- **Files to read:** `06-imagery-texture.md`, `01-typography.md`, `03-layout.md`
- **Personality fit:** Primary — Editorial, Warm/Human. Strong — Playful, Brutalist, Technical, Organic.

## Page flow intent

This IS the person. The page has ONE job: express a voice and capture subscribers. Minimal pages: writing, about, subscribe.

Core rhythm: `name + one-sentence identity → recent writing (list, not grid) → subscribe input`.

That might be the entire homepage. If it's longer: add a featured/pinned post, a short bio paragraph in the margin, reading recommendations. The page should feel like opening someone's notebook, not visiting a website.

## Techniques

- Typography IS the entire design (Locomotive/Studio Dialect pattern)
- Editorial single-column layout for writing (max 680px, 1.7 line-height)
- Signature element: one distinctive creative choice that defines the site
- Minimal navigation (writing, about, subscribe — that's it)
- Newsletter signup as primary CTA (single input + button)
- Grain/noise texture for warmth
- Reading time estimates on posts
- Hand-drawn or custom SVG elements for personality

## Font direction

Make a statement. This is YOUR identity. A variable serif for writing, a bold sans for your name, a mono for metadata. Be opinionated.

## Color

Personality-driven. Not corporate. Consider monochromatic with one surprise color. Warm backgrounds (cream, not white).

## Motion budget

LOW. Writing needs focus. Page transitions between posts if multi-page. Subtle hover states. Nothing competing with content.

## Anti-patterns

Cookie-cutter blog template. Sidebar widgets. Multiple newsletter popups. Social icons everywhere.
