# Recipe F: Editorial / Content

## Quick ref

- **When:** Magazine, blog, journalism, data storytelling, long-form publication.
- **Token budget:** ~15k (HARNESS + layout + imagery + motion + typography + anti-similarity).
- **Files to read:** `03-layout.md` > Editorial Grid, `06-imagery-texture.md` > Editorial Design, `05-motion.md` > Scrollytelling, `01-typography.md`
- **Personality fit:** Primary — Editorial. Strong — Creative, Brutalist, Warm/Human, Organic.

## Page flow

```
[Hero story — full-bleed image with overlaid headline + byline + reading time. NOT a landing page hero — a STORY entry.]
    ↓
[Story feed — NOT uniform cards. Magazine layout:
  - Lead story: full width, large image, large headline
  - 2-column pair: medium stories side by side
  - Pull quote or data callout: full width, centered, large serif
  - 3-column row: smaller stories
  - Full-bleed feature image
  - 2-column pair again
  Each row is DIFFERENT. Rhythm varies.]
    ↓
[Category filters — sticky horizontal strip that appears on scroll. Tabs, not dropdowns.]
    ↓
[Data story or interactive — scrollytelling block: sticky visualization + scrolling narrative text]
    ↓
[Newsletter signup — single input, no modal. Inline with content.]
    ↓
[Footer — multi-column link directory. Dense, newspaper-style.]
```

Key: NO two rows of the feed should use the same layout. The grid VARIES like a magazine spread. Study NYT, Bloomberg, ProPublica.

## Techniques

- Multi-column editorial grid (varying column spans per content type)
- Magazine spread sections (alternate dramatically between layouts)
- Scrollytelling for data/narrative (Pudding: sticky graphic + scrolling text)
- Progressive disclosure via scroll depth
- Pull quotes in serif at dramatic scale
- Full-bleed images breaking the grid
- Per-story/section custom accent colors (Pudding: HSL per story)

## Font direction

High-contrast serif/sans pairing. Serif for headlines and pull quotes, sans for body. See `01-typography.md` > Editorial table.

## Color

Near-monochromatic base with surgical accent color use. Color serves section identity, not decoration.

## Motion budget

LOW-MEDIUM. Content is the star. Scroll-triggered reveals only. Scrollytelling where it serves comprehension. No decoration.

## Reference sites

The Pudding, Bloomberg.

## Anti-patterns

Sidebar clutter. Popup newsletters. Social share buttons obscuring content. Uniform section layouts.
