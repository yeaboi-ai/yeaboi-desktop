# Recipe U: Fintech / Banking

## Quick ref

- **When:** Financial products, banks, trading platforms, crypto, insurance, wealth management.
- **Token budget:** ~16k (HARNESS + dashboards + components + ergonomics + color + anti-similarity).
- **Files to read:** `08-dashboards.md`, `04-components.md`, `09-ergonomics.md`, `02-color.md`
- **Personality fit:** Primary — Professional, Technical. Strong — Luxury, Editorial. Bad fit — Playful, Brutalist, Bold, Organic.

## Page flow intent

TRUST before features. The page must answer "is this safe?" before "what does it do?".

Core rhythm: `product value prop + trust signals hero → live data visualization or calculator (interactive, proves capability) → feature breakdown → security/compliance badges → testimonials from named companies → pricing/plans → CTA`.

For trading platforms: the page should feel like the product (dark, data-dense, monospace numbers). For consumer banking: clean, calm, light.

## Techniques

- Trust-first hero: security badges, regulation mentions, partner logos above fold
- Data visualization as design element (animated charts, live ticker)
- Calculator or comparison tool as interactive CTA
- Monospace for all financial figures (tabular-nums)
- Card-based account/product comparison
- Step-by-step signup with progress indicator
- "Spaceship instruction manual" aesthetic for dashboards
- Dark mode as primary for trading/crypto

## Font direction

Geometric sans for precision. Monospace for data. No serifs unless targeting premium/wealth management.

## Color

Dark for trading platforms. Light for consumer banking. Semantic colors critical (green profit, red loss). Conservative accent — trust over excitement.

## Motion budget

LOW for consumer banking (trust = calm). MEDIUM for trading/crypto (data updates, chart animations). Number ticker animations for live data.

## Anti-patterns

"To the moon" crypto bro aesthetics. Hidden fees. Complex signup flows. Purple gradients (screams "AI startup" not "trust me with money").
