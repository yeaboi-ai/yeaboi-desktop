# Recipe N: Event / Conference

## Quick ref

- **When:** Festivals, conferences, launches, exhibitions, one-time happenings.
- **Token budget:** ~15k (HARNESS + motion + typography + color + page-archetypes + anti-similarity).
- **Files to read:** `05-motion.md`, `01-typography.md`, `02-color.md`, `07-page-archetypes.md`
- **Personality fit:** Primary — Playful, Bold. Strong — Professional, Luxury, Brutalist, Editorial, Warm/Human. Bad fit — Technical.

## Page flow

```
[Hero — event name at MASSIVE scale filling viewport. Date + location below. Countdown timer (monospace, large). "Get Tickets" as only CTA. Background: video loop or animated gradient blobs for energy.]
    ↓
[Lineup/speakers — horizontal scroll of portrait cards. Or: stacked full-width rows with name + role + headshot. Hover reveals bio.]
    ↓
[Schedule — interactive timeline, NOT a table. Day tabs at top. Time blocks visually sized by duration. Click expands detail. Color-coded by track/stage.]
    ↓
[Venue — full-bleed photograph or 3D render. Annotated with key areas. Map integration.]
    ↓
[Tickets — 2-3 tiers side by side. Prominent "sold out" states. Urgency via real availability numbers, not fake countdown.]
    ↓
[Sponsors — tiered logo grid: headline sponsors large, others smaller.]
    ↓
[FAQ — accordion. Addresses logistics: parking, accessibility, refund policy.]
```

Key: ENERGY. The page should feel like the event before it happens. Countdown is the heartbeat. Everything points toward "Get Tickets."

## Techniques

- Countdown timer as hero focal point (monospace, large scale)
- Full-bleed event photography or video background
- Speaker/lineup grid with hover-reveal bios
- Schedule as interactive timeline (not a table)
- Sticky ticket CTA that follows scroll
- Gradient blob backgrounds for energy (Springs Estate pattern)
- Marquee ticker for lineup/sponsors
- Clip-path reveals for section transitions

## Font direction

Bold display font for event name + clean sans for schedule/details. The event name should be the identity — massive, memorable.

## Color

Event-specific. Music festivals = vibrant. Tech conferences = restrained. Galas = dark + metallic. One palette per event, derived from event branding.

## Motion budget

HIGH. Events sell energy and anticipation. Parallax, reveals, ambient motion all appropriate.

## Anti-patterns

Generic Eventbrite/Luma embed. Stock photos of conference rooms. Dense text-heavy schedule.
